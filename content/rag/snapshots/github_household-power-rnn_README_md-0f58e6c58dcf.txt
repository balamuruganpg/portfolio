## 📖 Overview

Welcome to the **Household Power Consumption RNN** project! This repository showcases a complete, end-to-end Machine Learning pipeline focused on time-series forecasting. Using a Recurrent Neural Network (RNN) architecture built with TensorFlow and Keras, this project predicts future power usage based on historical electricity consumption data.

This project highlights my skills in:
- **Time-Series Data Preprocessing:** Handling missing values, scaling, and sequence generation.
- **Exploratory Data Analysis (EDA):** Visualizing trends, seasonality, and feature correlations.
- **Deep Learning:** Designing, compiling, and training a Recurrent Neural Network (RNN).
- **Model Evaluation:** Analyzing loss curves and visualizing model predictions against ground truth data.

---

## 🎯 Objectives
- To predict global active power consumption using historical data.
- To demonstrate proficiency in building time-series forecasting models using Deep Learning.
- To showcase thorough data exploration and visualization techniques.

## 🛠️ Tech Stack & Requirements

The project leverages the following industry-standard tools:
- **Python** (Core language)
- **TensorFlow / Keras** (Deep Learning framework)
- **Pandas & NumPy** (Data manipulation)
- **Scikit-learn** (Data preprocessing & metrics)
- **Matplotlib & Seaborn** (Data visualization)

### Installation
You can easily set up the environment using the provided `requirements.txt`:
```bash
pip install -r requirements.txt
```

---

## 🚀 How to Run
1. **Clone the repository:**
   ```bash
   git clone https://github.com/balamuruganpg/Household-Power-Consumption-RNN.git
   cd Household-Power-Consumption-RNN
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the Jupyter Notebook:**
   Open `Household-Power-Consumption-RNN.ipynb` in Jupyter Notebook, JupyterLab, or VS Code to explore the data, train the model, and view the results.

---

## 📁 Repository Structure
- `Household-Power-Consumption-RNN.ipynb`: The core Jupyter Notebook containing all EDA, modeling, and evaluation code.
- `requirements.txt`: Python package dependencies.
- `output_*.png`: Extracted visualizations and graphs.
- `SimpleRNN_household_power.keras`: The saved trained model.
- `household_power_consumption.csv`: The dataset used for training and testing.
